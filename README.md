# funpay-token-plugin

Модуль для твоего FunPay-бота на Python.
Когда человек покупает токены, бот **заходит на твой сайт под твоим аккаунтом (Sashka)**, создаёт ключ на нужное количество токенов и отдаёт его покупателю в чат.

Покупателю аккаунт на сайте **не создаётся** — он получает только ключ.

## Как это работает

```
FunPay → покупатель купил/написал → твой бот ловит сообщение
      → handle_purchase(...)          ← тут работает этот модуль
          1. понял, сколько токенов купили («2кк» → 2 000 000)
          2. зашёл на сайт под твоим аккаунтом (Sashka)
          3. создал ключ на столько токенов
          4. вернул сообщение с ключом → бот отправляет его покупателю
```

## Установка

```bash
pip install -r requirements.txt
```

## Быстрый тест без сайта (dry-run)

```bash
python demo_live.py
```

`dry_run: true` (по умолчанию) ничего не трогает — ключ будет `DRYRUN-...`.

## Настройка

1. `config.yaml` — уже с твоим логином `Sashka`
2. Впиши `site.base_url` — адрес твоего сайта
3. Настрой эндпоинты под свою админку (`login`, `create_key`)
4. `dry_run: false` — модуль начнёт реально создавать ключи

### Сколько токенов даёт лот

Если у лотов фиксированное количество — пропиши ID лота:

```yaml
amounts:
  lots:
    "123456789": 2000000   # лот «2кк токенов»
```

Если количество пишется в названии/тексте («2кк», «500к», «2000000», «2.5 млн») —
включено по умолчанию (`parse_from_text: true`).

## Встраивание в бота

Где-то при инициализации бота:

```python
from token_plugin import TokenPlugin

plugin = TokenPlugin.from_config("config.yaml")
```

В обработчике новой покупки/сообщения:

```python
result = plugin.handle_purchase(
    order_id="fp_12345",             # ID заказа FunPay — защита от повторной выдачи
    buyer_username="Иван2024",       # юзернейм покупателя на FunPay
    item_name="2кк токенов",         # название лота (или передай lot_id)
    message_text="хочу 2кк",         # текст сообщения, если количество в нём
)

if result.message:
    await chat.send(result.message)   # отправить покупателю (у тебя — своя функция)
if not result.ok:
    log.error("Ошибка выдачи ключа: %s", result.error)
```

`result.duplicate == True` — этот заказ уже обрабатывался, повторно ключ не создаётся.

## API-контракт сайта

| Запрос | Метод | Ответ |
|---|---|---|
| `/api/login` | POST (логин, пароль) | 200 = ок |
| `/api/keys/create` | POST `amount`, `username` | `{"key": "ABC-123"}` |

Имена путей и полей полностью настраиваются в `config.yaml`.

## Правила безопасности

- `config.yaml` содержит пароль от сайта → **не заливай его в git**
- `config.yaml` уже в `.gitignore`
- Ставь `dry_run: false` только после успешного прогона `demo_live.py`
